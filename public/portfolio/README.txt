世男 Sky · 一页式个人主页

使用方法
1. 本版本专门适配 NotionNext：将本文件夹中的内容完整上传到 NotionNext 仓库的 public/portfolio/。
2. 部署后访问 https://你的域名/portfolio/index.html。
3. 样式和图片使用 /portfolio/ 根路径，不会再因 NotionNext 重写网址而错误请求 /styles.css。
4. 将 15 张原图放入 images 文件夹，并按下列编号命名为 JPG；页面会自动替换编号占位框。
5. 如果图片是 PNG 或 WebP，请转换为 JPG，或在 index.html 中把对应的 .jpg 改成实际扩展名。
